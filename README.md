## 功能与开源范围

本仓库是「理堂」的完整源码（**不是裁剪版**），包含：

- 首页：校园通知聚合（全校 63 个二级站点、7000+ 条，按竞赛/教学/讲座等分类筛选，本院优先）
- 搜索：本地通知检索（标题/部门/分类，离线 BM25，不依赖服务端）
- 地图：自绘校园地图（瓦片加载、地点搜索、双击课程定位教室）
- 我的：课表、成绩、绩点、专业排名、培养计划
- 学习通：课程、作业、考试、讨论、签到（数字口令 / 扫码 / 雷达）
- 一网畅学（Tronclass）：课表、待办、考试、课件
- 校历、作业/考试提醒、自动更新
- 论坛：找搭子功能**尚未开放**，当前页面为示例数据；入口暂时保留

### 关于登录（请以本节为准）

三个系统的登录方式并不相同，凭据都只保存在本机：

| 系统 | 登录方式 | 本地保存 |
|---|---|---|
| 教务 | App 内通过学校 CAS 登录 | 会话 cookie；勾选「记住登录」时，学号与密码也会用系统密钥库（Keystore / Keychain）加密保存 |
| 学习通 | 内嵌学习通官方登录页，密码只输入在对方页面 | 只保存会话 cookie |
| 一网畅学 | 复用教务登录态静默认证 | 只保存会话 cookie |

- 「记住登录」**默认开启**，可在登录页关闭；关闭后只保存会话 cookie。已保存的教务凭据可在「我的」点「退出」清除。
- 密码与 cookie 只在本机使用，不上传、不写日志、不经过本项目服务器（本项目没有服务器）。
- 登录后只读取当前账号本人可见的数据，不提供代刷、代签、批量操作。

### 数据来源与边界

- 通知来自学校各二级单位**公开网页**上的公开信息，只保存标题、发布单位、分类、发布日期与原文链接。
- 本项目**不做加密破解、不逆向登录协议**；页面结构变化可能导致部分功能暂时失效。
- 地图底图版权归学校所有，仅用于校内信息展示；如权利方提出要求，会移除相关内容。

1. **信任与稳定（当前主线）**：发版纪律、文档与实现一致、数据源健康监控、本地诊断。

## 发布流程

内部发版清单不入库，简要步骤：

```bash
# 1) 打包（从「中性路径」构建，避免把本机用户名写进 libapp.so）
flutter build apk --release

# 2) 写 update.json（会自动算 sha256、拼下载地址）
node tools/release/set-update.mjs \
  --apk build/app/outputs/flutter-apk/app-release.apk \
  --version 0.4.4 --code 20 \
  [--mandatory] --notes "这次改了什么"

# 3) 提交 + 推送，然后在 GitHub / Gitee 建 Release
#    上传 APK 并重命名为 app-release.apk

# 4) 发布后自查
node tools/release/check-update.mjs

# 5) 本地备份：Project_USST_backups/v<版本>-full/app-release.apk
```

**Release 标题与 tag**：标题统一为 `LiTang-<version>`（如 `LiTang-0.4.4`）；tag 仍用 `<version>`（如 `0.4.4`，不要 `v0.4.4`）。Gitee 的下载地址按 tag 拼接，GitHub 侧用 `releases/latest/download`，两者都与标题无关。

**强制更新**：加 `--mandatory` 会把 `minVersionCode` 设成这一版的版本号，
低于它的客户端启动时会被要求先更新（弹窗不可关闭，带「手动下载」兜底）；
不加就是普通可选更新。注意 0.4.1 及更早的客户端不认识这个字段，只有 0.4.2+ 受管。
